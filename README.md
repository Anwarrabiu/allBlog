**AllBlog** Web Application 
  - Is a web application develop using MERN(MongoDB, Express, React and NodeJS) stack
  - It consist of CRUD(Create, Read, Update and Delete) functionalities
  - It consist of authentication and authorization features to restrict confidentiality and integrity
  - The primary function of the app is to provide numerous available blog posts to the public posted by different individuals where one can
    register and start posting their respective and interesting posts.
